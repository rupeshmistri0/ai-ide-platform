# AI IDE Platform Monorepo

Enterprise monorepo structure for an AI-powered Integrated Development Environment (IDE).

## Structure
- **apps/**: Frontend, desktop wrapper, and backend REST/Websocket API.
- **packages/**: Shared modules, common configs, and styling designs.
- **workspace/**: Context files and folder targets for runtime user workspaces.
- **models/**: Local LLM checkpoints, adapters, and prompt definitions.
- **plugins/**: Plugins SDK and registry system for third-party extensions.
- **docker/**: Multi-container orchestration logic.
